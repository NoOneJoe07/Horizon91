1. VISION FONDATRICE
────────────────────
La Division Web n'est pas une agence web ordinaire. Elle est le premier point
de contact de Groupe Supernova avec le marché régional — la porte d'entrée par
laquelle les PME de Beauce, Bellechasse et Chaudière-Appalaches découvrent ce
que la technologie peut faire pour elles, concrètement, à un prix juste.

Le positionnement est délibéré : nous ne sommes pas en compétition avec les
agences de Québec ou Montréal. Nous servons le client qu'elles ignorent — le
gym de quartier, la coiffeuse, le constructeur en bois rond, la courtière
immobilière, le praticien en ésotérisme. Des entrepreneurs qui ont besoin d'une
présence web professionnelle mais qui n'ont ni le budget ni l'appétit pour une
agence urbaine à 300$/h.

Le différenciateur central est la sécurité intégrée dès la conception. Chaque
site livré sort avec les headers OWASP, HSTS preload, CSP, DKIM/DMARC,
conformité Loi 25 Québec. Ce n'est pas un add-on — c'est le standard de base.
C'est aussi ce qui crée le pont naturel vers la Division Cybersécurité.


2. STACK TECHNIQUE — AVANTAGE CONCURRENTIEL RÉEL
──────────────────────────────────────────────────
Là où la majorité des agences régionales livrent du WordPress ou du Wix,
Groupe Supernova Web construit avec la stack des grandes équipes :

  - Next.js 15/16 App Router + TypeScript + Tailwind CSS v4
  - next-intl — internationalisation native FR/EN/ES dès le départ
  - Prisma + PostgreSQL — projets avec base de données
  - Stripe — intégration paiement e-commerce complète
  - Vercel — déploiement cloud, SSL automatique, CDN mondial
  - Zoho Mail / Resend — courriel transactionnel professionnel

Ce choix technique garantit des sites rapides, sécurisés, évolutifs et
maintenables sur 5 à 10 ans. Un client qui démarre avec une vitrine peut
évoluer vers l'e-commerce complet sans tout reconstruire.

facturé à l'abonnement mensuel indépendamment des contrats de développement.
